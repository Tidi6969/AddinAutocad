
# DDimnotes

Dự án DDimnotes trong bộ AddinAutocad.

## Quy tắc version
- Giữ nguyên định dạng tên file gốc.
- Mỗi bản build tăng version tiếp theo.
- Ví dụ: DDimnotes-V67.zip, DDimnotes-V68.zip.
- Changelog lưu trong thư mục Log hiện có.
- Không tạo thêm thư mục Log mới.

## Cấu trúc dự án
- src/: mã nguồn
- data/: dữ liệu dự án
- Log/: ghi chú thay đổi
- releases/: file zip các phiên bản
