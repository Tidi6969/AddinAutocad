# DDimnotes

Dự án DDimnotes trong bộ AddinAutocad.

## Quy tắc version
- Giữ nguyên định dạng tên file gốc.
- Mỗi bản build tăng version tiếp theo.
- Ví dụ: DDimnotes-V91.zip, DDimnotes-V92.zip.
- Changelog lưu trong thư mục Log hiện có.
- Không tạo thêm thư mục Log mới.

## Đường dẫn chuẩn
DDimnotes/

## Quy tắc lưu trữ
- releases/: lưu file zip các phiên bản
- Log/: lưu changelog từng phiên bản
- README.md: mô tả dự án

## Quy tắc version
- File phát hành: DDimnotes-Vxx.zip
- Changelog: Log/changelog-Vxx.md
- Khi tạo bản mới, tăng số version tiếp theo.
- (Đọc GitHub repo AddinAutocad, vào đúng thư mục DDimnotes, kiểm tra bản mới nhất rồi tiếp tục.)
