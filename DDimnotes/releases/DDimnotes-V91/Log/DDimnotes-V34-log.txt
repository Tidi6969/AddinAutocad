DDimnotes V34

- Added persistent settings file DUser\DDimnotes_settings.ini.
- Settings file uses plain numeric lines only.
- List values are saved as indexes:
  0 Mode index: 0=D, 1=B, 2=A
  1 Angle index: 0=0deg, 1=90deg, 2=180deg, 3=270deg
  2 Create Notes: 0/1
  3 Create Marks: 0/1
  4 Note width factor
  5 Note text color ACI
  6 Side-view distance scale
  7 Dim offset scale
  8 Note position index: 0=Xmax,Ymax, 1=Xmin,Ymin
  9 Note offset X scale
  10 Note offset Y scale
- Does not store MIS_SET.SET or ti.dat data values.
- If DUser is missing from AutoCAD Support File Search Path, show a safe warning and use built-in defaults.
- Version: 1.0.34.0.
